# Fashion ML Evaluation & Business Strategy Capstone

## Overview
Comprehensive evaluation pipeline, business recommendations, and reporting for an omnichannel apparel, textiles, and fashion retail enterprise.

### Directory Structure
- `data/evaluation_metrics.json`: Evaluated metrics for Demand Forecasting and Customer Return Risk.
- `notebooks/model_evaluation.ipynb`: Interactive Jupyter analysis script with visualizations.
- `reports/Week4_Comprehensive_Evaluation_Report.docx`: Complete executive-level assessment and strategic roadmap.
- `assets/`: Exported high-resolution performance plots.
- `generate_report.py`: Script to rebuild the formal Word report document.
- `requirements.txt`: Python package requirements.

## Quick Start
```bash
pip install -r requirements.txt
python generate_report.py
```
